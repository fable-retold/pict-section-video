Two standalone pict-section-video players, each with its own control bar (play / seek / time / volume / rate / fullscreen). Seeking rides the browser's native HTTP Range requests, so the scrubber jumps without downloading the whole clip. This is the same class pict-section-fileview mounts as its video lens; here it runs on its own.
