Video HLS
pict-section-video · orator-file-service

Adaptive-bitrate playback end to end. retold-media-ladder encoded two synthetic clips (npm run make-media) into HLS packages: a master playlist with the 540p rung first, one single-file fMP4 rung per height, a poster and a download. orator-file-service addPackageRoute serves them with HTTP Range, private, no-cache playlists and immutable media, even though this server gzips every other response. Each package plays in a standalone pict-section-video (natively on Safari, through hls.js elsewhere; use the quality menu or data saver), and the landscape package also plays inside a pict-section-fileview with downloads on, whose fullscreen button goes really fullscreen (on an iPhone, by handing off to the video child's native player). The line under each player is its live getState().
